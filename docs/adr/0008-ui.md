# ADR-0008: UI as a stay companion, Tailwind v4, modern-web-guidance

**Status:** accepted · **Phase:** UI

## Options presented
- Guest UX: **stay companion** *(recommended, chosen)* vs full-page chat vs floating widget.
- Styling: CSS Modules + tokens *(recommended)* vs **Tailwind v4** *(chosen)*.
- Surfaces: guest portal, group request + live pipeline, staff console, metrics + architecture *(all chosen)*.

## Decision
- **Guest:** reservation card, loyalty perks and one-tap requests beside the concierge.
  Chat replies render as actionable cards: hold → checkout, cancellation terms → confirm
  dialog, case numbers, cited policies. An "Agent internals" toggle shows router, tools,
  latency and guardrails for technical audiences.
- **Groups:** a public form or pasted email, with a live view of the ADK workflow graph.
- **Staff:** hand-off queue with the full packet; replies flow back into the guest's chat;
  desk approvals; a sales desk with one-click approval of Rescue options; metrics and live
  architecture diagrams.
- **Tailwind v4 tokens** use `light-dark()` + `color-scheme` (both themes).
- **GoogleChrome/modern-web-guidance** was consulted per pattern: IME-safe enter-to-submit;
  `<dialog closedby="any">` with a light-dismiss fallback; autofill tokens on sign-in and
  payment; `:user-invalid` validation; `popover="manual"` toasts with `ariaNotify()`;
  responsive tables with container queries; links (not tabs) for page navigation;
  `<progress>` spinner; Temporal `PlainDate` for stay dates (polyfilled on demand).
- **Next.js 16 with Cache Components:** static shells; URL-dependent bits inside `<Suspense>`.
- **Charts** follow the dataviz skill: the single-series hue was validated with the palette
  script (light `#2a78d6`, dark `#3987e5`), with a hover/focus tooltip and a table view.
